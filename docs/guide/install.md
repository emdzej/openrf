# Installing

1. Download `OpenRF-<version>-macos-universal.zip` from the
   [releases page](https://github.com/emdzej/openrf/releases) and unzip it.
2. Move `Return Fire.app` wherever you like (e.g. `/Applications`).
3. OpenRF is not notarized by Apple. The first time you start it, **right-click the app →
   Open**, then confirm. (Or run `xattr -dr com.apple.quarantine "/Applications/Return Fire.app"`.)
4. Give it the [game data](./game-data).

Prefer to build it yourself? See [Build from source](/howto/build-from-source).
