# Controls

The original default key bindings:

| Action | Player 1 | Player 2 |
|---|---|---|
| Forward / back | W / S (or ↑ / ↓) | Num 8 / Num 5 |
| Turn left / right | A / D (or ← / →) | Num 4 / Num 6 |
| Button 1 (fire, launch, dock) | H | Num − |
| Button 2 | J | Num + |
| Button 3 | K | Num Enter |
| Button 4 / 5 (turret, strafe) | Q / E | Num 7 / Num 9 |
| Self-destruct | H + J + K | Num − + Enter |

| Vehicle | H | J | K | Q / E |
|---|---|---|---|---|
| Tank | Fire cannon | Lobbed shot | — | Rotate turret |
| Jeep | Throw grenade | Boat mode (in water) | Drop flag | — |
| Support vehicle | Fire rockets | Fire rockets | Drop mine (2 player) | — |
| Helicopter | Guns | Guns | Missile | Strafe left / right |

Global keys:

| Key | Action |
|---|---|
| F2 | Start a one-player game (title screen) |
| F3 | Start a two-player game (title screen) |
| 1–9 / Shift + 1–9 | Start the first 1P / 2P map of a difficulty level (title screen) |
| Alt + 3 | Swap sides (exchange the two keyboard layouts) |
| Esc | Leave the level |
| Alt + Enter | Toggle fullscreen |
| M | Mute / unmute the game |

## Gamepads

Gamepads work alongside the keyboard (not in the original, which read joysticks through its key
bindings). The first connected pad drives player 1, the second player 2 (in a two-player game; Swap
Sides exchanges them too). Buttons are named by position, like on a SNES pad: **A** east (right),
**B** south (bottom), **X** north (top), **Y** west (left); on an Xbox pad that is B, A, Y, X, on a
PlayStation pad circle, cross, triangle, square.

| Pad | In the game | Keyboard equivalent |
|---|---|---|
| D-pad or left stick | Forward / back, turn | W A S D |
| A | Button 1 (fire, launch, dock) | H |
| B | Button 2 | J |
| X | Button 3 | K |
| A + B + X | Self-destruct | H + J + K |
| L / R (shoulders or triggers) | Buttons 4 / 5 (turret, strafe) | Q / E |
| START | Launch (in the bunker vehicle select) | H |
| SELECT | Swap sides (two players) | Alt + 3 |
| START + SELECT | Leave the level / the map viewer | Esc |
| Y | (unused) | |

| Pad, title screen | Action | Keyboard |
|---|---|---|
| Pad 1 START | Start a one-player game | F2 |
| Pad 2 START, or pad 1 SELECT | Start a two-player game | F3 |
| Any button | Skip the intro stills and movies | any key |

The map viewer takes the d-pad to scroll and L / R to change map. The same mapping serves hosts that
only offer virtual pads (the [gasm](./gasm) build: its pads 0 and 1 are pads 1 and 2 here, with the
same button bits; `gasm-run` maps two keyboard layouts onto them).
