Play Return Fire in your browser

OpenRF runs here as openrf.wasm on the gasm runtime: the same engine as the desktop app, with the graphics, maps, movies and music read from your own Return Fire CD. Nothing from the game is on this site, and nothing you pick leaves your computer.

What you need

  • The Return Fire CD for Windows 95, as a disc in a drive, a mounted disc image, or a folder you copied it to. How to mount an image.
  • A recent Chrome, Edge, Firefox or Safari. The browser copies the CD (about 280 MB) into its private storage for this site once, so later visits start at once.
  • A keyboard or a gamepad; two players can share one keyboard.

Your CD

Imported:

The browser may clear site data when disk space runs low.

Or choose the CD again below to replace it.

Pick the folder that holds RFIRE.BIN, ART and SOUND: the CD itself (/Volumes/RFIRE, drive D:) or a copy of it.

    Importing copies the files into this site's private browser storage (OPFS). Playing without importing reads them from the folder you picked, which you'll need to pick again next time.

    Controls

    The game sees two gamepads. Connected gamepads take them in connection order; without gamepads, the keyboard plays both (player 2's keys work while fewer than two gamepads are connected). More in Controls.

    PadIn the gamePlayer 1 keysPlayer 2 keys

    Title screen: START starts a one-player game, SELECT (or player 2's START) a two-player game. In play, SELECT swaps sides and START + SELECT leaves the level. High scores are kept in this browser.

    Keyboard layout

    One binding per line: <pad 1-4> <button> <key code>.... Buttons: a b x y l r select start up down left right; key codes are KeyboardEvent.code names. The same format as gasm-run --keymap.
